What is Cloud Computing?

Cloud computing is the delivery of computing resources and services over the Internet. Instead of purchasing, installing, and maintaining all computing infrastructure locally, organizations can use servers, storage, databases, networking, software, and development platforms provided by cloud companies.

These computing resources are usually available on demand. Users can increase or decrease the amount of resources depending on their requirements.

Simple Definition

Cloud computing means using computing resources through the Internet instead of depending entirely on computers and servers located inside your own organization.

Examples of Cloud Resources

🖥

Virtual Servers

Computers running inside cloud data centers.

💾

Cloud Storage

Online storage for documents, images, backups, and other files.

🗄

Databases

Managed database systems available through cloud platforms.

🌐

Networking

Virtual networks, IP addresses, load balancers, and firewalls.

📱

Applications

Software applications accessed directly through a web browser or mobile application.

🧑‍💻

Development Platforms

Environments that developers use to create, deploy, and manage applications.

Teacher's Explanation:

A simple example is Google Drive. Instead of storing every document only on your computer, the file can be stored on Google's servers and accessed through the Internet.

Infrastructure as a Service — IaaS

IaaS

Infrastructure as a Service

IaaS provides virtualized computing resources through the Internet.

In an IaaS environment, the cloud provider manages the physical data center, servers, storage, networking, and virtualization technology.

The customer is usually responsible for managing the operating system, installed software, application data, and application configuration.

IaaS Commonly Provides

  • Virtual machines
  • Virtual CPUs
  • RAM
  • Cloud storage
  • Virtual networks
  • Firewalls
  • IP addresses
  • Load balancers

Examples of IaaS Services

AWS

Amazon EC2

Provides virtual computing instances that can run operating systems and applications.

Microsoft Azure

Azure Virtual Machines

Allows organizations to create and manage Windows or Linux virtual machines.

Google Cloud

Compute Engine

Provides customizable virtual machines running inside Google's infrastructure.

Example Scenario

A university wants to host its own student information system online. The IT department wants complete control of the operating system, server configuration, database software, and security configuration.

Instead of purchasing a physical server, the university rents a virtual machine from a cloud provider.

Recommended Model: IaaS

Advantages of IaaS

  • High level of control
  • Flexible resource configuration
  • Easy server scaling
  • No need to purchase physical servers
  • Suitable for customized systems

Limitations of IaaS

  • Requires technical knowledge
  • User manages operating systems
  • User manages applications
  • Security configuration remains important
  • More administration than PaaS or SaaS
04

Platform as a Service — PaaS

PaaS

Platform as a Service

PaaS provides a managed development and deployment environment for applications.

PaaS is commonly used by software developers. Instead of managing virtual machines, operating systems, patches, and much of the server infrastructure, developers can focus primarily on creating their applications.

The cloud provider manages the infrastructure, virtualization, operating system, middleware, and often runtime environments.

PaaS Commonly Provides

  • Application hosting
  • Programming language runtimes
  • Deployment tools
  • Database integration
  • Application monitoring
  • Automatic scaling
  • Development frameworks
  • Server management

Examples of PaaS Services

Google

Google App Engine

Allows developers to deploy applications without directly managing the underlying servers.

Microsoft

Azure App Service

Provides managed hosting for web applications and APIs.

Render

Web Services

Allows developers to deploy web applications from source code repositories without manually configuring traditional servers.

Example Scenario

A group of students created a Node.js web application. They want to deploy the project online without manually installing Linux, configuring a web server, or managing a physical machine.

They upload the application code to a cloud platform, and the platform handles much of the server environment.

Recommended Model: PaaS

Advantages of PaaS

  • Faster application development
  • Less server administration
  • Built-in deployment tools
  • Automatic infrastructure management
  • Ideal for software developers

Limitations of PaaS

  • Less infrastructure control
  • Platform restrictions may exist
  • Possible vendor dependency
  • Some programming environments may not be supported
  • Migration between providers may require changes
05

Software as a Service — SaaS

SaaS

Software as a Service

SaaS provides complete software applications through the Internet.

In SaaS, almost the entire technology stack is managed by the service provider. Users normally only need a browser, application, Internet connection, and valid account.

Users do not normally manage the servers, operating systems, application runtime, or software installation.

Common SaaS Applications

  • Email platforms
  • Online document editors
  • Video conferencing platforms
  • Cloud storage interfaces
  • Customer relationship management systems
  • Project management systems
  • Learning management systems

Examples of SaaS

Google

Google Workspace

Gmail, Docs, Sheets, Drive, and other productivity applications are accessed online.

Microsoft

Microsoft 365

Provides cloud-based productivity and collaboration applications.

Zoom

Zoom

Users access a complete communication service without managing its infrastructure.

Example Scenario

A teacher wants to create documents, presentations, spreadsheets, and online class materials.

Instead of installing and maintaining an application server, the teacher opens Google Docs or Microsoft 365 and immediately begins working.

Recommended Model: SaaS

Advantages of SaaS

  • Easy to use
  • No server management
  • No complex installation
  • Automatic software updates
  • Accessible from many devices

Limitations of SaaS

  • Limited application customization
  • Usually depends on Internet access
  • Users depend heavily on the provider
  • Data is stored on external infrastructure
  • Subscription fees may apply

Cloud Responsibility Model

One of the easiest ways to understand IaaS, PaaS, and SaaS is to examine who manages each layer of the technology stack.

Technology Layer IaaS PaaS SaaS
Applications Customer Customer Provider
Data Customer Customer Mostly Provider / User Content
Runtime Customer Provider Provider
Middleware Customer Provider Provider
Operating System Customer Provider Provider
Virtualization Provider Provider Provider
Servers Provider Provider Provider
Storage Provider Provider Provider
Networking Provider Provider Provider
Managed by Customer Managed by Cloud Provider Shared / Depends on Service

EASY ANALOGY

Understanding IaaS, PaaS and SaaS Using Pizza

A common analogy for cloud computing compares the service models to preparing or buying pizza.

IaaS

Rent a Kitchen

The kitchen and equipment are provided, but you prepare and manage most of the meal yourself.

More control, more responsibility.
PaaS

Pizza Ingredients Prepared

Much of the environment is prepared for you. You focus mainly on creating the final product.

Focus on development.
SaaS

Restaurant Pizza

Everything is prepared for you. You simply use or consume the finished service.

Least technical management.

09

How to Choose a Cloud Service Model

Do you need complete control over the operating system and server?
Choose IaaS
Do you mainly want to develop and deploy an application?
Choose PaaS
Do you only need a finished application that is ready to use?
Choose SaaS

Remember

As we move from IaaS → PaaS → SaaS, the cloud provider manages more components, while the customer manages fewer components.

10

Advantages of Cloud Service Models

💰

Reduced Hardware Cost

Organizations can reduce the need to purchase and maintain expensive physical servers.

📈

Scalability

Computing resources can be increased or decreased according to demand.

⚡

Fast Deployment

Servers and applications can often be deployed in minutes instead of waiting for physical equipment.

🌍

Accessibility

Cloud services can generally be accessed from different locations through the Internet.

🔄

Maintenance

Cloud providers handle varying levels of infrastructure maintenance.

🛡

Managed Infrastructure

Providers maintain physical data centers, networking, and underlying hardware.

11

Limitations and Considerations

Internet Dependency

Many cloud services require stable Internet connectivity.

Data Privacy

Organizations must understand where data is stored and how the provider protects it.

Vendor Lock-In

Moving applications between cloud platforms can sometimes be difficult.

Ongoing Costs

Cloud services may charge based on usage, subscriptions, storage, bandwidth, or computing resources.

Service Outages

Applications may temporarily become unavailable when the provider experiences an outage.

Security Responsibilities

Cloud providers secure their infrastructure, but customers are still responsible for properly protecting accounts, data, and configurations.

Practical Scenarios

Scenario 1

Virtual School Server

A school needs a Linux server and wants its IT administrator to configure Apache, PHP, MySQL, firewall rules, and the operating system.

Show Answer
IaaS

The school requires significant control over the server, operating system, and installed applications.

Scenario 2

Student Web Application

Students created a Node.js application and want to deploy it online without manually managing Linux servers.

Show Answer
PaaS

A managed application platform allows students to focus on their source code.

Scenario 3

Online Document Editing

A teacher wants to create documents using a browser and does not want to configure servers or install server software.

Show Answer
SaaS

The teacher needs a finished software application rather than infrastructure or a development platform.

Scenario 4

Software Development Team

Developers need automatic deployment, application logs, runtime management, and scaling while they focus on programming.

Show Answer
PaaS

PaaS provides managed application development and deployment infrastructure.
